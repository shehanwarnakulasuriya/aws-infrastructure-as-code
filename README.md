# AWS Infrastructure as Code

Infrastructure as Code examples using AWS CloudFormation, showcasing cloud architecture, networking, and infrastructure automation.

## Overview

This repository contains AWS Infrastructure as Code examples designed to demonstrate cloud architecture, networking, automation, and deployment best practices.

The first example provisions a basic AWS VPC networking foundation using AWS CloudFormation.
